Restaurant Sales Dashboard

Power BI dashboard analyzing restaurant sales and customer behavior.

Overview

This project explores:

-Customer demographics (age, gender, region)
-Most ordered food items
-Quantity sold
-Average ratings
-Regional performance

Key Metrics:

-Total Quantity Sold
-Average Rating
-Top Food Item
-Highest Sales Region

Tools:
-Power BI
-Power Query
-DAX

File:
Open the .pbix file using Power BI Desktop to interact with the dashboard.
